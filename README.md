# Agritas App

Agritas App is a comprehensive Flutter-based application designed to manage a variety of agricultural resources, including products, services, dealers, and real-time weather information. Built using the MVVM architecture, the app leverages Hive for efficient local data storage and caching, enhancing offline access and performance.

## Key Features

1. **Service and Dealer Management**
   - View and manage agricultural services, including details and providers for each service type.

2. **Crops and Products Management**
   - Access a categorized list of agricultural products and crops, complete with details and management functionalities.

3. **Weather Integration**
   - Real-time weather updates based on the user’s location to provide relevant environmental data.

4. **Problem Reporting**
   - A feature to view and manage issues related to crops and other agricultural challenges.

5. **Map and Location Tracking**
   - Integration with maps for tracking and locating dealers and service providers efficiently.

6. **Localization Support**
   - Language selection for enhanced user accessibility and a seamless multilingual experience.

7. **Caching with Hive**
   - Using Hive for caching frequently accessed data locally, improving the app’s performance and reducing network dependencies.
